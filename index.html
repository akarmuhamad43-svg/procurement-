const SUPABASE_URL = 'https://xxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGci...';

  2. لە SQL Editor، کۆدی database-setup.sql جێبەجێ بکە.
  3. لە Settings ← API، URL و anon key کۆپی بکە.
  4. لێرە دایانبنێ و فایلەکە پاشەکەوت بکە.
